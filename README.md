# Cristina Alexandre Peluquería · Dénia

Propuesta de web para Cristina Alexandre Peluquería (C/ Quevedo, 1 · Dénia).
Web estática (HTML, CSS y JS sin dependencias en ejecución) en `src/`.

- Publicada: https://alexsivera.github.io/cristina-alexandre-peluqueria-denia/
- Investigación y decisiones: `docs/` (business brief, experiencia de producto, dirección creativa, contenidos, QA).

## Desarrollo

```bash
npm install
npm run dev      # http://localhost:4330
npm run images   # regenera src/assets/img desde _src/img
npm run fonts    # copia las fuentes (Newsreader, Albert Sans) a src/assets/fonts
```

Cada push a `main` publica `src/` en GitHub Pages (`.github/workflows/pages.yml`).
